# Desktop app assets
- Use `icons/png/claudio-512.png` as the large app icon source.
- Use `icons/png/favicon.ico` for Windows/browser favicon contexts.
- macOS app distribution commonly requires an `.icns` icon set; generate it from the 1024px PNG using your packaging pipeline.
- Linux desktop entries can use `icons/png/claudio-512.png`.
- Check platform-specific packaging requirements before release.
