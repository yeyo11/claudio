# Desktop app assets
- The desktop app ships for Linux only: use `icons/png/claudio-1024.png` (or `icons/svg/claudio-app-icon.svg`) as the app icon source.
- The hicolor sizes are `icons/png/claudio-{16,32,48,64,128,256,512}.png`; 16–48 come from the micro icon.
- Use `icons/png/favicon.ico` for browser favicon contexts.
- Check platform-specific packaging requirements before release.
