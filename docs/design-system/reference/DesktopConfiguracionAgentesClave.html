Iniciar sesión en Claude Code

Claude Code no tiene un inicio de sesión que Claudio pueda hacer por ti. En tu propio ordenador, donde ya usas Claude, ejecuta claude setup-token en una terminal: abre el navegador, entras con tu suscripción y te muestra un token que dura un año. Pégalo aquí.

Cómo se crea el tokenSe guarda cifrado y solo lo reciben los procesos de Claude Code. No se vuelve a mostrar.
