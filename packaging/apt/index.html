Claudio apt repository

The signed apt repository of the Claudio desktop app for Debian and Ubuntu (amd64). Installing the .deb registers it on its own; these are the steps to add it by hand.

1. The key

Fingerprint 33DC 4ECF D406 1211 2D06 4758 43E6 487D 3DF5 098F (Ed25519, Claudio apt repository <yeyochico@gmail.com>).

sudo curl -fsSLo /usr/share/keyrings/claudio-archive-keyring.gpg \
  https://yeyo11.github.io/claudio/apt/claudio-archive-keyring.gpg
gpg --show-keys --with-fingerprint /usr/share/keyrings/claudio-archive-keyring.gpg

Check that the fingerprint printed is the one above. The armored key is claudio-archive-keyring.asc.

2. The source

Save this as /etc/apt/sources.list.d/claudio.sources:

Types: deb
URIs: https://yeyo11.github.io/claudio/apt
Suites: stable
Components: main
Architectures: amd64
Signed-By: /usr/share/keyrings/claudio-archive-keyring.gpg

3. Install

sudo apt update
sudo apt install claudio

From then on the system's updater installs new versions of the desktop app with its other updates. sudo apt remove claudio removes the source too.
